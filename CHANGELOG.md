# 📋 Changelog

All notable changes to the **SkyCart Weather Dashboard** project will be documented in this file.

The format is based on **Keep a Changelog** and follows **Semantic Versioning (SemVer)**.

## [1.0.0] - 2026-07-25

### 🎉 Initial Release

The first stable release of the SkyCart Weather Dashboard.

### ✨ Added

- Modern and responsive weather dashboard UI
- Real-time weather information
- City-based weather search
- Current location weather detection
- Dynamic weather cards
- Temperature display
- Humidity information
- Wind speed details
- Weather condition icons
- Sunrise and sunset information
- Responsive layout for desktop, tablet, and mobile devices
- Modern glassmorphism user interface
- Smooth animations and transitions
- Modular JavaScript architecture
- Organized project folder structure
- External Weather API integration
- Error handling for invalid city names
- Loading indicators for API requests
- Light and Dark theme support
- Clean and maintainable codebase

### 🎨 Improved

- User interface consistency
- Responsive spacing and layout
- Accessibility of UI components
- Performance optimization
- Code readability and maintainability

### 🛠️ Technical Highlights

- HTML5 semantic structure
- CSS3 Flexbox & Grid layout
- Vanilla JavaScript (ES6+)
- Modular code organization
- REST API integration
- Asynchronous data fetching
- Dynamic DOM manipulation
- Responsive web design principles

## 📌 Versioning Strategy

This project follows **Semantic Versioning (SemVer)**.

| Version | Description |
|---------|-------------|
| MAJOR | Breaking changes |
| MINOR | New features |
| PATCH | Bug fixes and improvements |

Example:

- **1.0.0** → Initial stable release
- **1.1.0** → New feature added
- **1.1.1** → Bug fixes
- **2.0.0** → Major architectural changes
