# 💻 Development Setup

## 1. Fork the Repository

Click the **Fork** button on GitHub.

---

## 2. Clone Your Fork

```bash
git clone https://github.com/YOUR_USERNAME/skycart-weather-dashboard.git
```

---

## 3. Navigate to the Project

```bash
cd skycart-weather-dashboard
```

---

## 4. Open the Project

Open the project in **Visual Studio Code**.

---

## 5. Create a New Branch

```bash
git checkout -b feature/your-feature-name
```

Example

```bash
git checkout -b feature/add-hourly-forecast
```

---

# 🌿 Branch Naming Convention

Use descriptive branch names.

Examples

```
feature/add-dark-mode

feature/weather-alerts

feature/hourly-forecast

bugfix/search-error

bugfix/api-timeout

docs/update-readme

refactor/ui-components
```

---

# 📝 Commit Message Convention

Follow the Conventional Commits specification.

Examples

```text
feat: add hourly weather forecast

fix: resolve search input validation

docs: update README

style: improve dashboard layout

refactor: simplify weather service

perf: optimize API requests

test: add weather utility tests

chore: update project configuration
```

# 📐 Coding Standards

Please follow these guidelines.

## HTML

- Use semantic HTML5 elements.
- Keep markup clean and readable.
- Use meaningful class names.

## CSS

- Organize styles logically.
- Use reusable classes.
- Maintain consistent spacing.
- Keep responsiveness in mind.

## JavaScript

- Use ES6+ syntax.
- Write modular code.
- Avoid duplicate logic.
- Handle API errors gracefully.
- Use descriptive variable and function names.

---

# 🔍 Before Submitting

Please ensure that:

- Code is properly formatted.
- No console errors exist.
- Responsive design works.
- Existing functionality is not broken.
- Code is clean and maintainable.

---

# 🔀 Pull Request Process

1. Fork the repository.

2. Create a new feature branch.

3. Make your changes.

4. Commit your changes.

5. Push the branch.

```bash
git push origin feature/your-feature-name
```

6. Open a Pull Request.

7. Clearly describe your changes.

8. Wait for review.

---

# 🐞 Reporting Bugs

When reporting bugs, please include:

- Operating System
- Browser
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots (if applicable)

---

# 💡 Feature Requests
