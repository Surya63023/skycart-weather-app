# 📌 Overview

SkyCart Weather Dashboard is a lightweight and modern weather application that displays accurate weather information using external weather APIs.

The project focuses on delivering an excellent user experience through:

- Clean architecture
- Responsive layouts
- Dynamic weather updates
- Beautiful animations
- Professional dashboard interface
- Modern design principles

The application is built completely using **Vanilla JavaScript**, making it lightweight, fast, and easy to maintain.

